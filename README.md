# Modelos-Heterocedasticos-Univariados-FOREX-EURUSD-D1-Spot(Câmbio À vista)

Estrutura quantitativa bayesiana em Stan/Python para o par EUR/USD. Combina Volatilidade Estocástica, Modelos Ocultos de Markov (HMM), LSTM pontual e uma hierarquia de decisão baseada em Price Action/SMC (varreduras de liquidez, níveis de preços redondos — *Big Figures* — e blocos de ordens) para fins de previsão e gestão de risco.
