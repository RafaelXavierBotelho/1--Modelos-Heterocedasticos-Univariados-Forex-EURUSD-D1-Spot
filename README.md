# Modelos-Heterocedasticos-Univariados-FOREX-EURUSD-D1-Spot(Câmbio À vista)

Bayesian quantitative framework in Stan/Python for EUR/USD. Combines Stochastic Volatility, HMM, Pointwise LSTM, and a tiered Price Action/SMC decision hierarchy (Liquidity Sweeps, Big Figures, and Order Blocks) for forecasting and risk management.
